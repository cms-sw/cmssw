# PhysicsTools/ONNXRuntimeAlpakaTest

Examples and tests for [PhysicsTools/ONNXRuntimeAlpaka](../ONNXRuntimeAlpaka), with the same models used by
[PhysicsTools/PyTorchAlpakaTest](../PyTorchAlpakaTest).

| module | features |
|--------|----------|
| `onnxtest::SimpleNet` | three `SOA_COLUMN`s packed into a `[batch, 3]` input; single-column `[batch, 1]` output used in place |
| `onnxtest::SimpleNet` with `featureMajor = True` | input and output used in place as `[3, padded size]` and `[1, padded size]` tensors, with `SimpleNetFeatureMajor.onnx` |
| `onnxtest::SimpleNetMiniBatch` | mini-batches, in a `stream::EDProducer` whose queue changes from event to event |
| `onnxtest::MultiHeadNet` | two outputs, written directly into the same SoA |
| `onnxtest::MaskedNet` | two inputs, `float` and `uint8_t`, from different SoAs |
| `onnxtest::TinyResNet` | `SOA_EIGEN_COLUMN` 9x9 matrices packed into a `[batch, 3, 9, 9]` input, and an Eigen vector output; optionally in mini-batches |

The `onnxtest::InspectionSink` checks the results against the known properties of each model, and fails the job if
any check fails:
  - SimpleNet: the results are finite, and do not depend on the layout or on the mini-batches;
  - MaskedNet: the eta feature is masked out, so the result is `pt + phi`;
  - MultiHeadNet: the regression head is in `[4, 5]`, and the classification head is a probability distribution;
  - TinyResNet: the logits are a probability distribution, and do not depend on the mini-batches.

Example run with 100 events, 4 streams, 4 threads, and the `CudaAsync` backend:
```sh
cmsRun ${CMSSW_BASE}/src/PhysicsTools/ONNXRuntimeAlpakaTest/test/runONNXRuntimeAlpakaTest.py -b cuda_async -ne 100 -ns 4 -nt 4
```
Use `--only` to run the selected models; each model is also run as an individual unit test for each backend.
See [python/options_cff.py](python/options_cff.py) for all the options.

## Models

The ONNX models in `data/` are generated by the scripts in `test/`, one per model, e.g.:
```sh
cd ${CMSSW_BASE}/src/PhysicsTools/ONNXRuntimeAlpakaTest/data
python3 ../test/SimpleNet.py
```
`SimpleNet.py` also exports `SimpleNetFeatureMajor.onnx`, the same model wrapped to accept and return transposed
tensors.

For integration in CMSSW, these files should be moved to a `cms-data` repository.
